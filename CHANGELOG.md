# Changelog

One row per change, oldest first. The version is the canon version the change
shipped in. Rulings are recorded in full in `DECISIONS.md`; this table is the
index to them.

| Date | Version | Item | Description |
|---|---|---|---|
| 2026-09-03 | 1.0.0 | Canon, and the entry point | Twenty rulings written against a measured census of fourteen surfaces — A1–A6 colour, B1–B3b type, C1–C2 depth and space, D1–D2 atmosphere, E1–E3 scope, F1–F3 the industrial accents. Each carries what was rejected. `build/check.py` measures canon on every run; `build/reference.py` generates the browsable reference from canon; `canon/surfaces.toml` records what each accent becomes on website, presentation and video, marked derived rather than ruled. A3 was re-ruled from link-role to artwork-only the same day, and the earlier reading is kept as a decision that changed. |
| 2026-09-03 | 1.0.0 | Deliveries and drift | Four deliveries split by surface, because mechanics depend on what a surface can consume: `solaros-web.css`, `solaros-canvas.css`, `solaros-tokens.json`, `solaros-tokens.toml`. Every name carries a `sol-` prefix so a delivery drops into any host without colliding, and hosts bind rather than copy. Each file header stamps the canon commit and the SHA-256 of the canon bytes it was built from. The canvas delivery states what it does not carry — no hover, focus or active, and no safe margin, because that has never been ruled. `build/drift.py` classifies every difference against a consumer as ruled, unbound or gap. |
| 2026-09-03 | 1.0.0 | design.md — the judgment half | What the deliveries cannot carry: the priority order when rules conflict, the token vocabulary to write instead of inventing values, the five accent rules, composition, the two copy registers and the named failure patterns. Every named failure has actually happened — a literal written instead of a binding, the ink literal reached for on a paper ground, two hues under 45 degrees used as a pair, a hover that changes hue, a 64-character hash at chrome size on a slide. `build/verify.py` closes the gap between the halves with 71 checks, so a judgment file naming a token that no longer exists fails loudly. |
| 2026-09-03 | 1.0.0 | Public mirror | The canon repo stays private; a separate public mirror carries only what is useful outside. `build/publish.py` stages `design.md`, the four deliveries, the reference page as `index.html` and `DECISIONS.md`. Withheld by default — a file is published only if `PUBLISH` names it. Redaction is applied to the staged copies only, so the private originals keep their real prose. The audit is the part that matters: it scans every staged file for absolute paths, first names and internal repo names, and blocks the push. It caught two misses on its first run. |
| 2026-09-03 | 1.0.0 | Primitives | 73 web classes and 46 canvas, authored in `build/primitives.css` and appended to the deliveries by the emitter. Each traces to an industrial accent in `canon/surfaces.toml` or to structure every artefact needs — the spec plate, the tick scale, the registration frame, the coordinate readout, the leader caption, the hazard band, the tear line. `design.md` publishes the class list as a closed API: a name not on the list does not exist. Bridge tokens let a primitive say "label sized" and leave the surface to decide what that means. The reference page renders every primitive live from the real delivery. |
| 2026-09-03 | 1.0.0 | Figures | Three parametric technical drawings shipped as `dist/solaros-figures.js` — `Solaros.rings()`, `Solaros.dispatcher()` and `Solaros.vsm()`. Each returns `{ explode(v) }` and binds itself to nothing. The port was mostly a rename, because canon's drafting weights were derived from these drawings in the first place. The palette suffix is gone: canon names the drawing ink as a role, so one class set serves both grounds and the same figure is correct on ink and on violet. `build/figures.test.js` asserts each generator emits real geometry, uses only published classes, and that `explode(1)` moves the parts. |
| 2026-09-13 | 1.1.0 | Vocabulary — ground, surface, format (G1) | Three words were being used for each other's jobs. Ground is a full role set — ink, paper, violet — and belongs to a section. Surface is the medium the work is made for — website, presentation, video. Format is the frame a piece is composed into — 16:9, 3:4, 1:1. The companion folder `surface-editions/` becomes `ground-editions/`, because what it holds is one edition per ground. A naming ruling: no value changes and no token is renamed. |
| 2026-09-13 | 1.1.0 | Icons — Lucide (G2) | No bespoke Solaros icon set is built. Lucide is the ruled source and is already a dependency across the estate; Streamline is the reserve where Lucide lacks a glyph. Canon carries the usage rules only and does not vendor, redraw or extend the set: stroke follows the drafting `visible` weight inside a drawing and Lucide's default 2px everywhere else, sizes are 16/20/24px on web and 24/32px on canvas, and colour is the ground's `text` role. Recorded so the absence of a bespoke set reads as a decision rather than a gap. |
| 2026-09-13 | 1.1.0 | Space and layout promoted into canon (G3) | Canon held no spacing values; `build/primitives.css` held them as literals — `16px` on `.sol-flow`, `8px` tight, `32px` between groups, and a twelve column grid on a `24px` gutter — and every artefact was already running on them. They move into `canon/tokens.toml` as `[space]` and `[layout]`, and primitives.css reads them back through `var()`. Five new custom properties in both deliveries, plus `space` and `layout` keys in the JSON delivery. New tokens, no value changed, nothing renamed; the rendered layout is byte-for-byte the same. Two values did not move: the safe margin is OPEN-4 and the baseline unit is OPEN-5. Both carry a marker and no number, and `build/check.py` fails if either is filled in without a ruling behind it. |
| 2026-09-13 | 1.1.0 | Accessibility — targets WCAG 2.2 AA (G4) | Canon states that Solaros targets WCAG 2.2 AA. It does not state that Solaros meets it, and that difference is the ruling. The colour floors are held by the build — 4.5:1 for text on its own ground, 3:1 for a graphical mark — and the rest of AA is a property of a finished artefact rather than of a token table. Two exceptions are declared, both on the paper ground: OPEN-3 `text_muted` at 3.17:1, and mono labels at 10–12px that run on the same value. |
| 2026-09-13 | 1.1.0 | Motion section in design.md | The motion rules written up as guidance. Motion is reserved for diagrams, state changes and video, and is never decoration. The durations and the one ease-out curve are tabled against what each is for. Explode and assemble is the motion primitive, at 900ms on that curve, and it is the only place a 900ms move is correct. A state change moves lightness and holds hue, so the same control reads as changed on every ground. Reduced motion settles with no travel, and the resting geometry is the same either way. |
| 2026-09-13 | 1.1.0 | Accessibility section in design.md | The non-colour AA criteria as a checklist worked through by hand — keyboard reach, visible focus, text resize to 200%, reduced motion honoured, and no information carried by colour alone. Review steps, not a conformance claim, stated as such so they are not read as one. |
| 2026-09-13 | 1.1.0 | Symmetric emit filter | The emitter writes `[space]` and `[layout]` into the web and canvas deliveries through one shared filter, so the two cannot drift apart. A key ending `_open` is a marker rather than a value and is held back, which keeps `OPEN-4` out of a stylesheet where a length belongs. `build/check.py` gained the matching guard. |
| 2026-09-13 | 1.1.0 | Reference regenerated | `dist/reference.html` rebuilt from canon so the browsable reference carries the new space and layout values rather than the previous set. |
